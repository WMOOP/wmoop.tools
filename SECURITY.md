# Security Policy

This repository follows the canonical WMOOP security policy:

- https://github.com/WMOOP/wmoop.doc/blob/main/SECURITY.md

Note the toolchain's specific supply-chain surface (generators, untrusted model input) described
there. **Reporting:** please report vulnerabilities privately via a GitHub security advisory on this
repository ("Security" → "Report a vulnerability"). Do **not** open a public issue for an
exploitable vulnerability until it has been triaged and a fix is available.
